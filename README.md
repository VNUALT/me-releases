# Molga Me: release downloads

This repository holds only the downloadable builds of Molga Me (`me` and `me-connector`), attached to its releases, plus their `SHA256SUMS`, license and notices. It contains no source code.

- **Downloads:** see [Releases](https://github.com/VNUALT/me-releases/releases).
- **Install with a package manager:** `npm install -g @molga/me`, or winget once the package is listed.
